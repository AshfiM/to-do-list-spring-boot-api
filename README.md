# TO-DO-LIST REST API 

- LANGUAGE - JAVA - VER 25
- BACKEND - SPRING BOOT - VER - 4.0
- DATABASE - MYSQL

## Architecture

- RESTful API design
- Mysql Database Integration
- Layered architecture

** Client --> Controller layer --> Service Layer --> Repository Layer --> Database Layer **

## Features
1. Create new task
2. Update task
3. Delete task
4. Retreive all tasks
